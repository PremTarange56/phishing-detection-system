Learn About Phishing

Understand how phishing attacks work, how to identify malicious URLs, and how to protect yourself online.

🎣 1. What is Phishing?

Phishing is a type of social engineering attack where cybercriminals attempt to deceive users into revealing sensitive information — such as usernames, passwords, credit card numbers, or bank details — by impersonating trusted entities.

The term "phishing" is derived from "fishing" — attackers cast a wide net (mass emails, fake websites) hoping that some victims will "take the bait."

⚠️ CNS Concept: Social Engineering
Social engineering exploits human psychology rather than technical vulnerabilities. Phishing is the most common form of social engineering attack, accounting for over 80% of reported security incidents worldwide.

Types of Phishing:

  • Email Phishing: Mass fraudulent emails impersonating banks, services, or organizations
  • Spear Phishing: Targeted attacks on specific individuals with personalized information
  • Smishing: Phishing via SMS text messages
  • Vishing: Voice phishing via phone calls
  • Whaling: Phishing targeting high-profile individuals (CEOs, executives)

⚙️ 2. How Phishing Attacks Work

A typical phishing attack follows these steps:

  1. Reconnaissance: Attacker researches the target and selects a trusted brand to impersonate
  2. Setup: A fake website is created that looks identical to the legitimate site
  3. Bait: Phishing emails/messages are sent with urgent calls to action ("Your account is suspended!")
  4. Hook: Victim clicks the malicious link and is directed to the fake website
  5. Capture: Victim enters credentials; attacker captures them
  6. Exploitation: Attacker uses stolen credentials to access real accounts
🔴 Red Flag — Urgency Tactics:
Phishing messages almost always create a sense of urgency: "Your account will be closed in 24 hours," "Verify immediately," "Suspicious activity detected." Legitimate organizations rarely demand immediate action via email.

🔗 3. What is a Malicious URL?

A malicious URL is a web address specifically crafted to deceive users or deliver harmful content. Attackers use various techniques to make malicious URLs appear legitimate.

Common Malicious URL Techniques:

1. IP Addresses instead of domain names:

🔴 http://192.168.1.100/login/verify — Uses IP address instead of domain

2. Brand name in subdomain (domain spoofing):

🔴 http://paypal.secure-verify.fake.com — PayPal is subdomain, not real domain
🟢 https://paypal.com — Actual PayPal domain

3. Typosquatting:

🔴 http://g00gle.com — Uses zeros instead of 'o'
🔴 http://paypa1.com — Uses '1' instead of 'l'

4. Using @ symbol:

🔴 http://legit.com@evil.com — Browser ignores everything before @

5. URL shorteners to hide true destination:

🔴 http://bit.ly/abc123 — Hides actual malicious destination

🔒 4. What is HTTPS? (HTTP vs HTTPS)

HTTP (HyperText Transfer Protocol) is the foundation of data communication on the web. HTTPS (HTTP Secure) is HTTP with an additional security layer called TLS/SSL.

HTTP (Insecure)

❌ Data sent as plain text
❌ Vulnerable to eavesdropping
❌ Susceptible to Man-in-the-Middle attacks
❌ No server authentication

http://example.com
HTTPS (Secure)

✅ Data encrypted with TLS/SSL
✅ Protected from eavesdropping
✅ Server identity verified
✅ Data integrity guaranteed

https://example.com
⚠️ Important Warning:
HTTPS only means the connection is encrypted — it does NOT mean the website is safe or legitimate! Many phishing websites now use HTTPS with free certificates (e.g., Let's Encrypt). Always verify the domain, not just the lock icon.

TLS/SSL (Transport Layer Security / Secure Sockets Layer) is the cryptographic protocol that powers HTTPS. It provides:

  • Encryption: Scrambles data so only intended parties can read it
  • Authentication: Verifies the server's identity via digital certificates
  • Integrity: Ensures data hasn't been tampered with in transit

🌐 5. Domain Names Explained

A domain name is the human-readable address of a website. Understanding domain structure helps identify phishing URLs.

Anatomy of a URL:
https://secure.paypal.com/login
https://Protocol/Scheme — how the browser communicates secure.Subdomain — can be anything the site owner chooses paypalDomain name — the actual registered name (check this!) .comTop-Level Domain (TLD) — country or category /loginPath — specific page on the website
Key Rule: Always read the domain name (the part just before the TLD). In http://paypal.secure-login.com, the actual domain is secure-login.com — NOT PayPal!

🎭 6. Why Attackers Use Fake Login Pages

Fake login pages (also called credential harvesting pages) are websites designed to look identical to legitimate websites in order to trick users into entering their username and password.

Why they work:

  • Modern browsers render HTML/CSS identically — making clones look perfect
  • Attackers copy the exact HTML/CSS of legitimate websites
  • Users are trained to trust visual appearance, not URL structure
  • Urgency and fear override careful thinking
  • Some fake sites even redirect to the real site after capturing credentials
🔴 Attack Flow:
User receives email → clicks link → lands on fake page → enters credentials → attacker captures credentials → user redirected to real site (doesn't suspect anything)

🔎 7. How to Identify Suspicious Links

Before clicking any link, check for these red flags:

1. Check the full URL, not just the display text
"Click here for PayPal" might link to "http://evil.com/paypal-fake/"
2. Look for misspellings in the domain
amazon → amazzon, google → g00gle, paypal → paypa1
3. Suspicious TLDs
.tk, .ml, .ga, .cf, .xyz are often used for phishing (free or cheap)
4. IP addresses instead of domain names
No legitimate service asks you to log in via an IP address
5. Very long URLs with many parameters
Legitimate sites rarely use extremely long URLs with many query parameters
6. Unexpected urgency in accompanying message
"Act now!", "Your account is suspended", "Verify immediately"

🛡️ 8. How to Stay Safe from Phishing

Remember: Phishing attacks technical and human vulnerabilities. Awareness is your first defense.
  • Never click links in unexpected emails — navigate directly to websites
  • Enable Two-Factor Authentication (2FA) on all accounts
  • Use a password manager — it won't auto-fill on fake sites
  • Keep your browser and OS updated — they include phishing protection
  • Report suspicious emails to your email provider
  • Verify unusual requests via a separate communication channel
  • Use tools like this system to analyze suspicious URLs before visiting
  • Trust your instincts — if something feels off, it probably is

💡 Security Tips
🔍
Check the Domain Carefully
Read every character in the domain. One changed letter can lead to a phishing site.
📧
Distrust Unexpected Emails
Do not click links in unexpected emails. Navigate directly to websites by typing the address.
🔒
Check HTTPS First
Never enter passwords on HTTP pages. HTTPS is necessary but not sufficient for safety.
📱
Enable Two-Factor Auth
2FA protects accounts even when passwords are stolen. Enable it everywhere possible.
🚫
Don't Trust HTTPS Blindly
HTTPS means encrypted connection, not a trustworthy website. Verify the domain too.
✅
Verify via Official Sources
If in doubt, search for the official website through a search engine, not through provided links.
🔑
Use a Password Manager
Password managers only auto-fill on the correct domain, protecting against fake login pages.
📞
Verify Unusual Requests
If a colleague or organization asks for sensitive data, verify through a separate channel.
